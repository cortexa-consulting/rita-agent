# Contributing

Thanks for wanting to help. This repository is published from Cortexa
Consulting's own source, so we don't merge pull requests here: the next
release would write over them. The most useful things you can send are:

- **Something went wrong:** open an issue with the **Something in the kit
  went wrong** form. Use made-up names and numbers, never real client data.
- **An idea:** open an issue with the **An idea** form. Tell us about the
  work, not only the feature.
- **A security problem:** report it privately, as `SECURITY.md` explains.
  Please don't use a public issue.

If you've changed a skill or the tool for your own team, you're welcome to
(the license is MIT). Tell us what you changed and why in an issue, and
we'll consider it for a release, with credit if you'd like it.

Everyone taking part in issues here is asked to follow our
[Code of Conduct](CODE_OF_CONDUCT.md).
